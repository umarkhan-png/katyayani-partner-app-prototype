Rules the flow encodes

Reference

The detail behind these is in the Phase 2 document, Feature 2.

Plus-code fallback
When the pin reverse-geocodes to a code like 23XY+TF, the code is discarded — never shown, never stored. Only pincode, district, state and the coordinates survive, and Area becomes a required field on the next screen.
Geography authority
pincode_map_v2 (19,300 India Post pincodes) decides district, state and territory. Google's naming is a cross-check, never the record.
Type drives the ask
Shop → shop name + shop number · Warehouse → warehouse name + gate number · Home → person's name + house number · Other → place name + building number. Every type asks for a number or building.
Locked, not frozen
Pincode, district and state are locked by default with one explicit override; using it flags the address as Edited by you for Ops.
Never dead-end
Location denied, no search result, or Maps SDK unavailable — each has a way through: search, drop the pin manually, or fall back to the pincode form.
One pin, always
No address saves without confirmed coordinates. The text is for the delivery person; the point is what they navigate to.
